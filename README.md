## 🚀 Quick Setup & Run Instructions

```bash
# 1. Clone the repository
git clone https://github.com/kishan-777/Front-End-Engineering_Evaluation-based-project.git

# 2. Navigate to project folder
cd Front-End-Engineering_Evaluation-based-project

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

## 🌟 Key Features
1. **Responsive Navbar & Sidebar**: Brand logo, animated mic button, collapsible sidebar with active route highlights.
2. **Real-Time Word-Based Search**: Fast controlled component search with clear 0-match and matching count feedback.
3. **Category Chips**: Filter videos across Tech, React JS, DSA, Comedy, Music, Gaming, Minecraft, and Podcasts.
4. **Interactive Actions**: Real-time Like/Subscribe state toggles that automatically reflect across Watch History, Liked Videos, and Subscriptions feeds.
5. **Shorts Shelf & Dedicated Shorts Feed**: Vertical 9:16 video cards with engagement actions and channel identity.
6. **External Video Links**: Real YouTube watch links and channel URLs opening safely in new tabs (`window.open(url, '_blank')`).
